# ИС «Бдительность» — этап 2

## Состав

- `sql/` — скрипты базы данных.
- `tests/` — тесты базы на Java (JUnit 5 + JDBC), проект Maven.
- `report/report_stage2.tex`, `report/report_stage2.pdf` — отчёт. Пояснения, выделенные «**УДАЛИТЬ** … **УДАЛИТЬ**», нужно убрать перед сдачей. Собирается командой `xelatex report_stage2.tex` из каталога `report`; листинги берутся из `../sql`, рисунки — из `../img`.
- `report/report_stage2_old.*` — прежняя полная версия отчёта.
- `defense_notes.md` — вопросы и ответы к защите.
- `../srs/beholder_srs.*` — SRS, согласованный с базой; номера требований в отчёте и SQL-комментариях соответствуют ему.
- `img/er_model.png`, `img/datalogical_model.png` — модели, вставленные в отчёт; `img/er.drawio`, `img/datalogical.drawio` — их исходники для draw.io.

## Скрипты

| Файл | Назначение |
|---|---|
| `install.sql` | Создание базы целиком (выполняет 01–04) |
| `00_drop.sql` | Удаление всех объектов |
| `01_create.sql` | Типы, таблицы, ограничения, справочные данные |
| `02_triggers.sql` | Триггеры целостности (10) |
| `03_functions.sql` | Функции для критически важных запросов (7), представления (3) |
| `04_indexes.sql` | Индексы (6) |
| `05_fill.sql` | Тестовые данные; выполняется на только что созданной базе |
| `06_fill_bulk.sql` | Массовые данные для проверки индексов (необязательно, около 10 с) |

Бизнес-логика (условия подачи заявок, правила ИЛ, уведомления, права) реализуется в Spring; база обеспечивает целостность данных и даёт функции для атомарных операций и сложных выборок.

## Установка на helios

```bash
cd sql
psql -h pg -d studs -f 00_drop.sql     # при повторной установке
psql -h pg -d studs -f install.sql
psql -h pg -d studs -f 05_fill.sql
psql -h pg -d studs -f 06_fill_bulk.sql   # по желанию
```

Требуется PostgreSQL 11 или новее. Объекты создаются в текущей схеме.

Учётные записи тестовых данных: `manager` / `manager123`, жильцы `gromov`, `belova` и др. / `resident123`.

## Тесты

Каждый тест работает в своей транзакции и откатывает её, поэтому база не меняется. Нужные строки тест создаёт сам, так что тесты проходят и на пустой базе (после `install.sql`), и на заполненной.

| Класс | Что проверяет |
|---|---|
| `DbTest` | Базовый класс: подключение, откат, помощники |
| `IntegrityTest` | Ограничения таблиц и триггеры: журналы баланса и ИЛ, вместимость квартиры, статусы заявки и доноса, основание наказания |
| `FunctionTest` | Каждая из 7 функций |

Запуск (нужны JDK 17+ и Maven):

```bash
cd tests
DB_URL=jdbc:postgresql://localhost:5432/beholder DB_USER=postgres DB_PASSWORD=... mvn test
```

Для базы на helios сначала откройте туннель `ssh -p 2222 -L 5432:pg:5432 sXXXXXX@se.ifmo.ru`, затем укажите `DB_URL=jdbc:postgresql://localhost:5432/studs`, `DB_USER=sXXXXXX` и свой пароль.
